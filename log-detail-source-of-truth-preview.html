What changed in the code

  • New file — Workouts/TheWorkoutBlock.swift. The single implementation of THE WORKOUT: renders the description, offers + ADD THE WORKOUT when there isn't one, and opens the one editor.
  • Deleted — the journal's editorialNotesComposer / notesEditor (~110 lines) and the receipt's workoutRecipeSection (~70 lines). They were two editors for one database column under two different labels, writing to two different rows.
  • One row, always — the block writes the row the receipt reads from and mirrors onto the journal row in the same save, so a Strava-linked run (which is two rows) can't hold two different answers.
  • Global Edit no longer touches the description. It used to write a value seeded when the sheet opened, which could silently overwrite a newer edit. That column now has exactly one door.
  • The date — WorkoutRepReceiptView gained a placement flag. Standalone it renders the mono datestamp rule; embedded in a journal entry it renders no date header at all.
