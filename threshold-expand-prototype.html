What changed, and what deliberately didn't

Still one time control. Both panes are bound to the same window. Change the range in the sheet and the tab behind it is already changed — the sheet does not own a second range that can disagree with the page. That was the rule in CLAUDE.md and it holds.

Still one renderer. The chart in the sheet is the same view as the chart in the card, handed a taller frame. There is no second threshold chart to drift.

Still one band. The controls in the sheet write to the same shared BandSettingsStore, so the Signal Lab's threshold section cannot start disagreeing with this one about the same miles.

The three moves

  • Sticky window bar. It was already at the top of the scroll and already had 30d/3mo/6mo/1yr/custom. It just scrolled away above four long sections. Now it pins, and shrinks slightly once stuck so it costs less of the screen. 30 D relabels to 1 MO.
  • Expand. A chevron-out button on the section head, plus the whole "Adjust ›" line, open a full-screen detail. The inline card stays exactly as it is for the glance.
  • Tabbed controls. Anchor / Band / Minimum / Floor were four blocks stacked into roughly 700pt of scroll. As tabs they are one screen, and each tab's current value shows on the tab itself, so the read is still complete without opening anything.
