Post Run Drip — BroadsheetDirection II · Aug 2026

A running app that reads like a sports weekly.

The first system was a clean product UI. This one is a printed page: newsprint stock, one hot ink, a display serif with real contrast, and the athlete's own words treated as the article rather than a caption.

Scoped as --bs-* and .bs-* in broadsheet/broadsheet.css, so it sits beside the original without touching a single token of it.
