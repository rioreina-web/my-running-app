Why the headline is Instrument Sans.

Haas Display is a licensed Monotype face and the only files going free are rips, so it is out. These are the measurements that picked its replacement — the Haas row was captured while the real file was briefly installed.

The widest pair on the page: Inter sets 10.3% longer at the same size, on a bigger x-height with more open apertures. An Inter headline needs roughly 9% less size to occupy the same line. It reads as software; Haas reads as print.

The closest free match by measure — +3.1%, less than a third of Inter’s drift. Squarer bowls and a flatter terminal on the y, but in a phone masthead the line breaks in the same place, which is the thing that actually matters.

Haas kicks the leg out straight from the bowl. Inter curves it, which softens the whole word.

Haas closes the aperture tight. Inter opens it for small-size legibility — the single biggest tell.

Haas has a vertical spur. Inter drops it entirely, so caps rows read flatter.

Inter's flag and foot serif make figures unambiguous. This is why Inter still owns the data role.

The decision.

Haas earned its place at display size and nowhere else — and at 46px, Instrument Sans holds the same line for free. What the system actually needed was one tight grotesk on the headline against tabular Inter on the numbers.

The licence did fall through, so this is now the decision: Instrument Sans on the headline, at the same size and tracking. It sets 3.1% wider than Haas — the smallest drift of any free face here, and close enough that lines break in the same place. Schibsted Grotesk looks right in character but measures the widest on the page (+10.5%), so it takes the labels instead, where width costs nothing.

Never as a display substitute: Inter. Keeping Inter on the numerals and Haas on the headline is the contrast this system is built on — collapsing both into Inter is how the type stops meaning anything. Archivo is ruled out on era, not measure.
