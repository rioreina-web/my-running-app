Why these charts

Volume — the bars answer "how much," but the new bits answer "is it safe": a 4-week average line and an ACWR band showing where this week sits against the 0.8–1.3 sweet spot.

Key sessions — a pace-progression plot, colored by workout type so threshold/interval/MP trends don't blur together, plus a tap-through to the rep splits of any session.

Mood — a daily ribbon (not weekly dots) makes the day-after-long-run dip visible, with a distribution and the verbatim quote behind it.

Niggles — recurrence swimlanes, one row per body part, severity-encoded, with the load context and the athlete's own words. Surface, never diagnose.

Drill-down model

Every overview track is a button → a full detail screen, Back returns. The overview stays the signature shared timeline; depth lives one tap away.
